# Taisuru Constituency — Community Registration

## Run it
Open `index.html` in Chrome/Edge/Firefox.

No installation or server is required.

## Files
- index.html — page structure
- style.css — visual design and responsive layout
- script.js — validation and submission behavior

## Important
The form currently saves the latest submission to the browser's localStorage.
That means it does NOT send submissions to a real database.

For real submissions, connect the JavaScript form to a backend/database or a form service.
